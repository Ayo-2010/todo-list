# Taskly

A to-do list that keeps your day organised.

## Features

- Add, edit, complete and delete tasks
- Filter by all, active or completed
- Live progress bar and remaining count
- Saves to your browser, plus a dark mode

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
